# 🐙 타코타코! 타코야끼 가게

2000년대 플래시게임 감성의 타코야끼 장사 게임.

3분 제한시간, 12구 철판의 서로 다른 굽기 속도, 4번째 손님부터 소스 여부를 맞춰야 하는 주문 챌린지가 있습니다.

## 🎮 GitHub Pages

Repository **Settings > Pages** → Source **Deploy from a branch** → Branch **main**, folder **/(root)** → Save.
공개 게임 링크: https://shw7648-max.github.io/PERSONAL/

## 🐙 Streamlit Community Cloud

[share.streamlit.io](https://share.streamlit.io/) → Create app → GitHub 저장소 `shw7648-max/PERSONAL`, branch `main`, main file `streamlit_app.py` → Deploy.

## 로컬 실행

- 웹: `index.html`을 브라우저에서 열기
- Streamlit: `pip install -r requirements.txt && streamlit run streamlit_app.py`

마우스 조작, 키보드 1~5 도구 전환, Space 서빙이 가능합니다.
